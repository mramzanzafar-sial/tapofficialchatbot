# تنظیم اساتذہ پاکستان — معلوماتی چیٹ اسسٹنٹ

مکمل اسٹیٹک ویب ایپ (HTML + CSS + JavaScript) — کوئی بیک اینڈ، کوئی API کی، کوئی بیرونی ڈیپینڈنسی نہیں۔ GitHub Pages پر براہِ راست ہوسٹ ہو سکتی ہے۔

A fully static chatbot web app (HTML + CSS + JavaScript) — no backend, no API keys, no external dependencies. Hosts directly on GitHub Pages.

## فائلیں / Files

| فائل | کام |
|------|-----|
| `index.html` | اردو (RTL) چیٹ صفحہ — عنوان، پیغام ایریا، فوری موضوعات کے بٹن، ان پٹ باکس |
| `styles.css` | سبز/سفید تھیم، موبائل فرسٹ ریسپانسیو ڈیزائن، گول چیٹ ببلز |
| `app.js` | نالج بیس + اردو ٹیکسٹ نارملائزیشن + اسکورنگ میچر |
| `README.md` | یہ فائل |

## خصوصیات / Features

- اردو سوالات کے جواب: تعارف، دستور، نصب العین، اغراض و مقاصد، طریق کار، رکنیت، مرکزی و صوبائی ذمہ داران، خواتین ونگ، منصوبہ عمل 2026-2027، اجلاس شیڈول، نصاب، ضابطہ اخلاق، رابطہ
- نام لکھنے پر فرد کا مکمل رابطہ کارڈ (فون + ای میل)
- اردو نارملائزیشن: اعراب، ي/ی، ك/ک، ة/ہ اور ہمزہ کی شکلیں یکساں
- نامعلوم سوال پر اندازہ نہیں لگاتا — مرکزی ای میل `TAPofficial1969@gmail.com` کی طرف رہنمائی
- سسٹم فونٹس — آف لائن بھی چلتا ہے

## GitHub Pages پر لگانا / Deploy

1. اس فولڈر کے مواد کو GitHub ریپو میں پش کریں
2. Settings → Pages → Deploy from branch → `main` / root منتخب کریں
3. سائٹ کا لنک سب کے ساتھ شیئر کریں

تمام حقائق تنظیم کی دستاویزات (دستور 2026ء، تعارف، منصوبہ عمل سیشن 2026-2027) سے لیے گئے ہیں۔
